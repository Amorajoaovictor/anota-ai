# Coleta de dados — conhecendo os usuários

## Objetivo

Entender como programadores registram ideias, planejam tarefas, acompanham projetos e usam ferramentas de organização.

## Usuário inicial

O projeto nasceu de uma necessidade real do próprio criador, que será o primeiro usuário observado.

## Dados já disponíveis

- Necessidade de centralizar ideias, tarefas e roadmap.
- Uso combinado de notas, Kanban e planejamento.
- Incômodo com atualização manual e informações espalhadas.
- Interesse em usar inteligência artificial para organizar informações.

## Plano de coleta rápida

- Registrar durante uma semana situações em que uma ideia, tarefa ou prioridade é perdida.
- Anotar quais ferramentas são usadas e em que momento.
- Medir tempo gasto para transformar uma ideia em tarefa planejada.
- Entrevistar de 3 a 5 programadores com perfil semelhante.

## Perguntas de pesquisa

1. Onde você registra ideias de projetos?
2. Como transforma uma ideia em tarefa executável?
3. Como define prioridades?
4. Como acompanha o roadmap?
5. O que mais incomoda nas ferramentas atuais?
6. O que você confiaria à inteligência artificial?

## Limitação

Até que novos usuários sejam consultados, as conclusões representam hipóteses baseadas no criador do projeto.
